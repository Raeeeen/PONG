# PONG — Android Game

PONG is a simple Pong game I developed as a **school project** using Android Studio. It was my **first game development project** and also my first exposure to implementing AI in a game.

The game features a basic **rule-based AI opponent** that controls the paddle based on the position of the ball. While the AI is relatively simple, the project gave me my first experience with game logic, player input, collision detection, and implementing an AI opponent.

This project was mainly created as a learning experience and as an introduction to Android game development.

## Features

* Classic Pong gameplay
* Player-controlled paddle
* Rule-based AI opponent
* Ball and paddle collision
* Android mobile support

## Technologies Used

* Android Studio
* Java
* Android SDK
